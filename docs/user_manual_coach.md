# 教练端快速上手（Android App）

目标：新教练 30 分钟内完成安装 → 首次同步 → 记第一节成绩。

## 1. 安装（5 分钟）

1. 找管理者要 APK（或 GitHub Release 下载 `app-universal-release.apk`）。
2. 手机允许"安装未知来源应用"后安装。
3. 首次启动需阅读并同意《用户协议》与《隐私政策》。

## 2. 首次配置（10 分钟）

1. **登录教练名**：设置 → 教练姓名（签到记录会归属这个名字）。
2. **连接 PC**（和电脑在同一 Wi-Fi 时）：
   - 设置 → 桌面同步 → 「自动发现 PC」→ 自动填好地址；
   - 点「测试连接」确认绿色提示；
   - 开启「自动同步」开关。
3. USB 场景（没 Wi-Fi）：数据线连 PC（开 USB 调试）→ PC 会自动映射，无需填 IP。

## 3. 日常三件事

### 签到上课
首页 → 今日课时 → 点「签到」→ 上完点「签退」。签到自动消耗课时包余额。

### 记成绩
学员详情 → 本次测评 → 输入成绩（支持 `4'05"` 或 `12.5` 这种格式）→
自动算得分与等级，不及格/满分都有标记。

### 拍照留档
学员详情 → 相机拍摄（照片加密存本机，可同步到 PC）。

## 4. 备份与恢复（重要）

1. 设置 → 数据管理 → 「一键备份所有数据」→ 第一次会让你选固定文件夹
   （**选 Download**，卸载不丢）。
2. 建议开启「自动备份」开关（默认开，每周滚动保留 5 份）。
3. **备份加密口令**（设置 → 数据管理）：设置后备份包加密，口令忘了备份就打不开，
   务必告诉管理者一起保管。
4. 换手机：新手机装 App → 恢复最新备份 → 输入同一备份口令。

## 5. 数据库加密说明（v1.0.5+）

本机数据用 AES-256 加密，密钥由手机安全芯片（Keystore）保管、无法导出。
换手机时本地加密数据不会自动跟随 —— 必须走「备份 → 新手机恢复」。

## 6. 和电脑 / 小程序互倒数据

- 手机 → PC：自动同步，或手动「立即同步」。
- PC → 手机：PC 改了数据，手机收到广播自动拉取。
- 小程序数据：管理者发来 `backup_*.json` → 设置 → 数据管理 → 「导入小程序数据」。

## 7. 出问题了？

- 同步失败：设置 → 桌面同步 → 「测试连接」看提示（会说明 Wi-Fi/USB 与延迟）。
- 数据异常：先「一键备份」再操作，然后联系管理者远程排查（附上操作时间）。
